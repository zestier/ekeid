# ekeid

*Pronounced "eek-id" — from the archaic "ekename" (an additional name), the word that eventually became "nickname".*

A service for remapping opaque identifiers and coordinate tuples between external coordinate systems.

See [`docs/`](docs/README.md) for the v1 design specs.
